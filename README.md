# Smart Home Thermostat

Smart Home Thermostat is an open-source project designed to monitor and control the temperature of a home. The project provides a foundation for a smart thermostat that can be expanded with additional features and smart-home integrations.

## Features

- Monitor the current room temperature
- Set a desired temperature
- Control heating
- Control cooling
- Support temperature scheduling
- Support future smart-home integrations
