# Code of Conduct

## Our Standards

Smart Home Thermostat is intended to be a welcoming and constructive open-source project. Contributors are expected to:

- Treat other contributors with respect.
- Communicate professionally.
- Provide constructive feedback.
- Accept different opinions and approaches.
- Focus discussions on improving the project.
- Help create an environment where people can learn and contribute.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or personal attacks
- Discriminatory or offensive comments
- Threats or intimidation
- Deliberately disruptive behavior
- Sharing inappropriate or private information about another person

## Resolving Problems

If a community member experiences a problem, they should report it to the project maintainers when possible. Maintainers will review concerns and take appropriate action based on the situation.

Contributors are encouraged to resolve disagreements respectfully and focus on the technical or project-related issue rather than the individual.

## Scope

This Code of Conduct applies to project discussions, issues, pull requests, and other project spaces where contributors participate.

## Enforcement

Project maintainers may remove inappropriate content, request changes in behavior, or restrict participation when necessary to maintain a respectful project environment.
